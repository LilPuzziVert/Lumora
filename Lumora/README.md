## 🚀 INSTALLATION GUIDE

### Prerequisites
- **Windows 11** (Required for full functionality)
- **Administrator Access** (For OS-level integration)
- **TouchDesigner** (Free version sufficient)
- **Visual Studio Build Tools** (For C++ compilation)
- **Rust Toolchain** (For performance components)

### Step-by-Step Installation

#### 1. Quick Install (Recommended)
```bash
# Clone and run the smart installer
git clone <your-repo-url> C:\Lumora
cd C:\Lumora
python installation/installer.py --full-setup
```

#### 2. Manual Installation
```bash
# 1. Install dependencies
./installation/dependencies.ps1

# 2. Build Rust components
cd automation
cargo build --release

# 3. Compile C++ components
cd ../system
mkdir build && cd build
cmake .. && make

# 4. Install Python dependencies
cd ../../core
pip install -r requirements.txt

# 5. Setup TouchDesigner
# Open ui/lumora_main.toe in TouchDesigner
# Install custom operators from ui/operators/

# 6. Install Windows Service
python installation/installer.py --service-only
```

## 🎮 HOW TO RUN LUMORA

### First Launch
1. **Complete Installation** using the guide above
2. **Restart your computer** (Required for service registration)
3. **Launch TouchDesigner** and open `ui/lumora_main.toe`
4. **Start the service**: Run as Administrator: `lumora-service start`

### Daily Usage

#### Option 1: Hotkey Access (Recommended)
- Press `Ctrl + Alt + L` - Opens main interface
- Press `Ctrl + Alt + Shift + L` - Quick AI prompt
- Press `Win + L` (hold 2 sec) - Voice activation

#### Option 2: System Tray
- Right-click Lumora icon in system tray
- Select desired action from context menu

#### Option 3: Voice Commands
- Say "Hey Lumora" to activate
- Natural conversation interface
- Context-aware responses

#### Option 4: TouchDesigner Interface
- Launch TouchDesigner
- Open `ui/lumora_main.toe`
- Experience the full visual interface

### Service Management
```bash
# Start Lumora service
lumora-service start

# Stop Lumora service
lumora-service stop

# Check service status
lumora-service status

# Restart service
lumora-service restart

# View logs
lumora-service logs
```

## 🔧 TROUBLESHOOTING

### Common Issues

#### Service Won't Start
```bash
# Check Windows Event Log
eventvwr.msc

# Reinstall service
lumora-service uninstall
lumora-service install

# Check permissions
# Run PowerShell as Administrator
```

#### TouchDesigner Issues
```
1. Ensure TouchDesigner 2023.11120+ is installed
2. Check Python version compatibility (3.9+)
3. Verify GPU drivers are updated
4. Check TouchDesigner license (Free version works)
```

#### Performance Issues
```
1. Check system requirements (8GB RAM minimum)
2. Close unnecessary applications
3. Adjust AI processing frequency in settings
4. Disable visual effects in low-power mode
```
